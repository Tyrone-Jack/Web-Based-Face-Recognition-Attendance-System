About This System

The Face Recognition Attendance System is a modern web-based application designed to streamline the process of tracking attendance using real-time facial recognition.

Built using face-api.js, JavaScript, and a Node.js backend, this system automates attendance capturing by recognizing faces from a webcam feed and logging their presence securely.

Its key features include:

  • Webcam face detection
  • Accurate attendance logging with date and time
  • CSV & PDF export options
  • Organized attendace form access

This project is part of the Computer System Project unit at Multimedia University of Kenya.

Developed by dedicated students to offer a simple yet efficient solution to traditional roll-call methods.
